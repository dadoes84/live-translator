# 实时翻译器 — 需求文档

> 版本 1.0 | 2026-5-30

---

## 1. 项目概述

基于 Tauri v2 + Vue 3 + TypeScript 构建的 Windows 桌面实时翻译工具。用户框选屏幕区域后，工具周期性截取该区域图片，通过 Windows OCR 识别文字，发送至 Deepseek AI 翻译为简体中文，最终在窗口中显示译文。

## 2. 窗口规范

| 属性 | 值 |
|------|----|
| 窗口尺寸 | 1600 × 900 px（16:9） |
| 缩放 | **不可拉伸** |
| 移动 | **可拖拽** |
| 标题栏 | **自定义**（`decorations: false`） |
| 标题栏按钮 | 置顶切换（📌）、最小化、关闭 |

置顶按钮：点击切换窗口 `alwaysOnTop` 状态，视觉上有激活/非激活区分。

| 控件 | 选项 | 默认值 |

## 5. AI 设置弹窗

点击「AI设置」按钮后弹出模态弹窗，包含：

| 控件 | 类型 | 说明 |
|------|------|------|
| API Key | 密码输入框 | Deepseek API Key，输入时遮蔽 |
| 模型 | 下拉菜单 | `deepseek-v4-flash` / `deepseek-v4-pro`，默认 v4-flash |
| Prompt | 多行文本输入框 | 发送给 Deepseek 的系统提示词，纯文本 |
| 检测 | 按钮 | 使用当前填写的 API Key 和模型发送一条简短测试请求，验证 API 设置是否正确。弹窗内显示检测结果（成功/失败 + 错误信息） |
| 保存 | 按钮 | 保存到配置文件，关闭弹窗 |
| 取消 | 按钮 | 放弃修改，关闭弹窗 |

模型切换说明：deepseek-v4-flash 默认开启思考模式，不需要额外设置 temperature、top_p 等参数；v4-pro 同理。

## 6. 选区功能

### 6.1 交互流程

1. 用户点击「区域设置」
2. 主窗口隐藏
3. 全屏透明置顶选区窗口显示（覆盖所有显示器）
4. 用户拖拽鼠标框选目标区域
5. 松开鼠标后显示工具栏（尺寸 + 确认/取消按钮）
6. 确认：坐标回传给 Rust 后端，保存到配置文件，恢复主窗口
7. 取消 / ESC：恢复主窗口

### 6.2 多显示器与 DPI 约束

- 选区窗口必须覆盖**所有显示器**的虚拟桌面范围
- 选框坐标使用**逻辑像素**保存
- 截图时根据 `window.devicePixelRatio` 换算为**物理像素**
- 每个显示器的 DPI 可能不同，需逐显示器处理
- 程序启动时设置 `PROCESS_PER_MONITOR_DPI_AWARE`

## 7. OCR 与翻译流程

### 7.1 完整流水线

```
定时触发 → 截图选区 → Windows OCR 识别 → 稳定检测 → Deepseek 翻译 → 显示译文
```

### 7.2 截图

- 使用 `xcap` crate 枚举所有显示器
- 找到选区所在的显示器
- 截取该显示器画面
- 按选区坐标（相对显示器）裁切为子图
- RGBA → BGRA 转换（Windows OCR 要求）

### 7.3 OCR 识别

- 使用 Windows 内置 `Windows.Media.Ocr` API
- 根据「OCR 语言」设置选择 `en-US` 或 `ja` 语言包
- 利用 `Lines()` API 获取每行 BoundingRect
- 根据行间 Y 轴间距判断是否换段（智能换行）

### 7.4 稳定检测逻辑（关键）

```
上一次 OCR 文本 = A
本次 OCR 文本 = B

if B == "" (空):
    → 无文本，重置稳定计时，显示「检测中...」

if B == A (文本未变):
    if 稳定时长 >= 0.5秒 AND 距上次翻译 >= 1秒 AND B != 上次翻译文本:
        → 触发翻译
    else:
        → 等待，显示稳定进度

if B != A (文本变化):
    → 重置稳定计时，显示「检测到文本变化...」
```

设计意图：避免「打字机式」逐字加载的字幕在半截时触发翻译，导致翻译结果不全。

### 7.5 Deepseek 翻译

- Endpoint：`https://api.deepseek.com/chat/completions`
- API Key / Model / System Prompt 均从配置文件读取
- 请求节流：OCR 结果未变化时跳过；上一请求未返回时等待
- 不设置 temperature / top_p / presence_penalty / frequency_penalty
- 后端提供 `test_api_connection` 命令：用当前 API Key + 模型发送一条极短翻译（如「hello」→ 中文），返回成功/失败信息，供 AI 设置弹窗的「检测」按钮调用

### 7.6 译文显示

- 仅显示译文（不显示原文）
- 根据 OCR 的换行信息智能分段
- 字体/字号/颜色/背景色由设置项控制
- 区域可滚动

## 8. 配置持久化

### 8.1 存储位置

`app_data_dir/config.json`（Tauri 标准路径，如 `%APPDATA%/com.live-translator.app/config.json`）

### 8.2 配置项

```json
{
  "scan_frequency": 3,
  "ocr_language": "ja",
  "font_family": "Microsoft YaHei",
  "font_size": 18,
  "text_color": "#ffffff",
  "bg_color": "#1a1a2e",
  "is_pinned": false,
  "api_key": "",
  "model": "deepseek-v4-flash",
  "prompt": "你是一个专业的本地化翻译器...",
  "region": {
    "x": 0,
    "y": 0,
    "width": 0,
    "height": 0
  }
}
```

### 8.3 加载/保存时机

- **加载**：应用启动时（`onMounted`）
- **保存**：任何设置项变更后 500ms 防抖自动保存

## 9. 状态栏

显示当前运行状态：

| 状态 | 说明 |
|------|------|
| 就绪 | 初始状态或停止后 |
| 请先设置翻译区域 | 未设选区时点击开始 |
| 检测中... | 未识别到文字 |
| 检测到文本变化... | 文本内容变化，等待稳定 |
| 检测到文本 (稳定 X.Xs) | 等待稳定或翻译间隔 |
| 翻译中... | 正在调用 Deepseek API |
| 运行中 | 翻译完成，等待下一轮 |
| OCR 识别失败 | OCR 出错 |
| 翻译出错 | API 调用失败 |

```
live-translator/
├── src/
│   ├── main.ts                    # 入口，挂载 App
│   ├── App.vue                    # 主页面（三段布局 + 全部逻辑）
│   ├── style.css                  # 全局样式（所有组件样式集中在此）
│   └── components/
│       ├── AreaSelector.vue       # 选区窗口组件（从 demo 搬运）
│       └── AiSettingsModal.vue    # AI 设置弹窗组件
├── src-tauri/
│   ├── Cargo.toml
│   ├── tauri.conf.json
│   ├── capabilities/
│   │   └── default.json
│   └── src/
│       ├── main.rs                # DPI 感知 + 入口
│       └── lib.rs                 # 所有 Tauri commands
├── docs/
│   └── requirements.md            # 本文档
├── index.html
├── package.json
├── vite.config.ts
└── tsconfig.json
```

### 样式约定

- **所有组件样式集中在 `src/style.css`** 中，不散落在各 `.vue` 文件的 `<style>` 块中
- 使用 CSS 变量定义颜色、间距、圆角等设计 tokens
- 组件仅通过 class 引用样式
